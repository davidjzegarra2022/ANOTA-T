# Origen

Skill copiada de https://github.com/lucasBecrod/skills-finangher (commit d0e16aa),
publicada por Finangher con licencia MIT (ver `LICENSE`). Sin cambios en el guion.

En ANOTA-T la misma lógica corre en `api/_shalom.js` para el botón
«Consultar en Shalom» del panel (bajo demanda, un pedido a la vez).

Requisito para usarla desde Claude Code: Node 18+ y Playwright con Chromium
(`npm install playwright && npx playwright install chromium` en esta carpeta, o
el Playwright global del entorno).
